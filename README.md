📋 Attendance Management System
A simple Java console-based application to manage and track student attendance.
This project follows a basic MVC-style structure using:

->Student → Model
->StudentController → Controller
->AttendanceView → View
->Attendance → Main class

🚀 Features
->Add and store student details (ID, Name)
->Display student list with attendance status
->Mark attendance as true/false
->Update and re-display attendance records

🛠️ Technologies Used
->Java
->OOP Concepts (Classes, Objects, Encapsulation)
->Collections Framework (List, ArrayList)
->Scanner for user input
